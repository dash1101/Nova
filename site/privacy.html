Privacy policy

For the Nova server, Nova web, the Nova Android app and the Nova Wear OS app · effective October 2026

In one sentence: Nova collects nothing about you. The apps talk only to the server you installed Nova on, and there is no Nova account, no Nova cloud, and no analytics or tracking of any kind.

Who runs what

Nova is open-source software (AGPL-3.0) that you install on your own computer. The project doesn't run any service that your data passes through. Whoever runs the server is in charge of the data on it — for a home server, that's you.

What stays on your server

  • The list of paired devices: each device's name, its public key (the private key never leaves the device) and when it was last seen.
  • Alerts and their history (your Inbox and Archive), and the settings you choose.
  • Whatever you set up yourself, such as backups, Cloudflare or Discord settings and a Home Assistant token. Tokens are stored on the server only and are never sent back to the apps.

None of this is sent to the Nova project or anyone else.

What the apps keep on your phone or watch

  • The device's own key pair, created in its secure hardware, used to sign every request.
  • Your server's address and certificate fingerprint, your appearance settings, a small cache of the last screens so the app opens quickly, and an optional wallpaper you pick.

What Nova connects to

Only what you'd expect, and never with your data: your own server; GitHub, to check for and download signed Nova updates; package mirrors and container registries when you install or update software; Cloudflare and Tailscale, only if you set them up for remote access; Discord, only if you add a webhook; Home Assistant, only if you connect a light; a speed-test server when you run a speed test; a public icon set for app icons; and DuckDuckGo for search suggestions on the Start page (which you can turn off).

Android permissions and why

  • Camera — only to scan the pairing QR code.
  • Notifications — to show your server's alerts and approval requests.
  • Biometrics — to confirm risky actions with your fingerprint or face.
  • Internet — to reach your server.
  • Install apps — to install Nova's own signed updates when you tap Update.
  • Run in the background and at startup — optional "Instant alerts": one quiet connection to your server so alerts arrive right away.

Crash reports

If the app crashes, it can send the error to your own server the next time it opens, so it shows up there. Nothing goes to the Nova project.

Children

Nova isn't directed at children and collects no personal information from anyone.

Changes and contact

If this policy changes, the new version is published here and in the source repository. Questions: open an issue at github.com/dash1101/Nova/issues.
