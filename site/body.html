Your home server, in your pocket.

Nova is a remote for the Linux box in your closet. Check its health, restart a container, set up drives and backups, and get alerts the moment something breaks. Every request is signed by a key that never leaves your phone's secure chip.

What you get

Everything you'd SSH in for, without SSHing in.

Health at a glance

CPU, memory, temperatures and network as live one-second graphs, plus drive health from SMART. One line tells you if anything needs attention.

Containers

Every Docker Compose app with logs, a shell inside it, start, stop, restart, update and restart policy. An app store installs popular self-hosted apps in a tap.

Drives and pools

A map of every drive and what it's for. A guided setup combines drives into one big folder, builds RAID 1, 5, 6 or 10, or makes a backup drive, with a "?" explaining each choice.

Backups

Scheduled, versioned snapshots to another drive or a NAS over SMB or NFS. A folder that suddenly loses most of its files isn't backed up over your good copy. Browse and restore from the app.

Alerts that reach you

A full drive, a container that died, a login from somewhere new. Instant notifications on your phone and watch without Google's push service, plus Discord if you like.

Diagnostics

Internet speed with ping and jitter, drive speed, a CPU stress test with live temperature and power, a memory test, and ping, traceroute and DNS tools.

Terminal

Real SSH to the server, with a key made inside the phone. One tap installs it on the server, after your fingerprint.

Several servers, several people

Pair with as many machines as you like. Invite family as Admin or View only, and approve browsers from your phone.

Nova web

The same app in any browser at https://your-server:8495. Anything risky asks your phone (or your watch) first.

Security

Built so a stolen password gets nobody in.

Nova has no passwords. Each phone and browser makes its own signing key, and the server only accepts requests that key signed.

Pair on your home Wi-Fi

Run sudo nova add and scan the code. Pairing only works from your home network, and each code works once.

Sign every request

The phone signs each request with a key in its secure chip, stamped with the time and a one-time number, so a recorded request can't be replayed.

Fingerprint for the risky stuff

Restarting, erasing drives or opening a terminal also needs a second key that only unlocks with your fingerprint.

Least privilege on the server

The API runs unprivileged in a systemd sandbox. The only root code is a helper with a fixed list of commands.

signed message = METHOD ␤ PATH ␤ TIME_MS ␤ NONCE ␤ sha256(BODY)
key = EC P-256 in the Android Keystore (StrongBox when the phone has one), never exportable

Every release is checked with an automated security test of more than 400 checks, and update packages are signed. Remote access goes through Cloudflare Access, so nothing is open to the internet.

Install

Three commands and a QR code.

Nova runs on any Linux with systemd — Debian, Ubuntu, Fedora, Arch, openSUSE and more — on anything from a mini PC to a Raspberry Pi.

Windows and macOS: the server isn't available for them yet — it's planned for 1.0. You can already use Nova from them: Nova web runs in any browser on Windows, macOS or Linux, pointed at your Linux server.

⚡

The quick way: one line on the server. It downloads the latest release, checks its signature, installs it (with apt on Debian and Ubuntu, so it updates like any package) and tells you what's next.

$curl -fsSL https://raw.githubusercontent.com/dash1101/Nova/main/get.sh | sh

Prefer to see it first? Read get.sh — it's short. Or do it by hand:

1

Download nova-server.deb (one package for x86-64 and ARM, like a Raspberry Pi) and install it. On a desktop, open it with your software app and choose Set up Nova in your apps — no terminal needed.

$sudo apt install ./nova-server.deb
2

Answer a few questions: your network, remote access (optional), where the server is, which tools to install. Type ? at any question for help; nova help and sudo nova doctor are there whenever you're stuck.

$sudo nova setup
3

Install the Android app on your phone (Android 7.0 or newer), then pair it. You can also open Nova web in a browser and approve it with sudo nova approve CODE.

Download the Android app Wear OS app

Your phone will ask to allow installs from your browser the first time. After that, Nova updates itself (Settings → Software update).

$sudo nova add

On the server

One command for everything.

sudo nova                 # every command, explained
sudo nova add             # pair a phone or tablet (with a countdown)
sudo nova approve CODE    # approve a browser, or something it's waiting on
sudo nova devices         # who has access
sudo nova remove NAME     # take it away
sudo nova status          # version, services, addresses
sudo nova update          # install the newest signed release
sudo nova backup now      # back up right away

Questions

Good to know

Safety and privacy

Can Nova read or send away my data?

No. Nova runs on your own server and the app only ever talks to that server. There's no Nova account, no Nova cloud and no analytics or tracking of any kind. Your files, photos and settings never pass through anyone else. The code is open source, so anyone can check this for themselves.

What does Nova connect to on the internet?

Only the services you'd expect, and never with your data. GitHub, to check for and download signed Nova updates. Your system's package mirrors and container registries (Docker Hub, GitHub's registry and others), when you install or update programs and apps. Cloudflare and Tailscale, only if you set them up for remote access. Discord, only if you add a webhook for alerts. Docker Hub's search, when you search the app store. A speed-test server, when you run a speed test. A public icon set, for app icons. DuckDuckGo, for search suggestions on the Start page as you type (you can turn them off).

Is it safe to install on my server?

Nova's API runs as its own unprivileged user in a systemd sandbox. The only part with root rights is a small helper that can run a fixed list of commands, and each one checks its input. Your containers, files and SSH settings are left alone unless you ask Nova to change them, and the risky changes also need your fingerprint.

What can someone do with a stolen phone or browser?

Very little. The phone's key only works after the phone is unlocked, and anything risky needs your fingerprint too. A browser can never do anything risky by itself: it asks an admin phone first. Remove a lost device with sudo nova remove NAME and its key stops working instantly.

How is Nova tested?

Every release goes through an automated security test of more than 500 checks against a real server: forged and replayed requests, stolen keys, path tricks, oversized requests, brute force, and more. Releases are signed, and the server only installs updates whose signature checks out.

Undoing things

How do I uninstall Nova completely?

sudo apt remove nova-server stops Nova and removes it. Your containers, apps and data stay exactly as they are. sudo apt purge nova-server also deletes Nova's settings and the list of paired devices. If Nova put apps on your Cloudflare account, run sudo nova cloudflare undo first. It lists what it added and asks before taking anything off.

Can I undo what Nova changed on Cloudflare?

Yes. Nova keeps a record of exactly what it added, and only ever removes those things. sudo nova cloudflare list shows them and sudo nova cloudflare undo takes them off. An address you had before Nova protected it keeps its login unless you say otherwise.

An update broke a container. Can I go back?

Yes. When Nova updates a container it keeps the version it replaced. If the new one won't start, Nova puts the old one back by itself. Any time later, open Containers → the container → Troubleshoot → Go back to the previous version.

I ignored an alert or archived something by mistake.

Ignored alerts that are still going on stay in the Inbox under "Ignored", with a "Stop ignoring" button. Archived events are kept on the server, and you can move them back from Inbox → Archive.

Can I go back to an older Nova version?

Yes. Download that version's .deb from the releases page and install it with sudo apt install ./nova-server_VERSION_all.deb (apt asks you to confirm going back). Your settings and paired devices stay on the server.

Using it

How do I set up Nova on several computers on the same network?

Install Nova on each one (the one-liner above, on each computer) and run sudo nova setup on each. Then pair your phone with every server: run sudo nova add on the next server and, in the app, tap the server name at the top of Home → Add a server, and scan its code. The app finds other Nova servers on your Wi-Fi by itself (they need udp port 8496 open), and you switch between them from that same menu. Each server keeps its own paired devices, so you can give someone access to one and not the other. In Nova web, add the others under Servers to see and control them all from one page.

Can several servers share one Cloudflare account, token and domain?

Yes. Make the API token once and use it on every server: on the first server open Settings → Cloudflare → Show the token (it needs your fingerprint), copy it, and paste it into Settings → Cloudflare on the next one. Everything a server adds to Cloudflare is labeled with that server's name, each server only ever changes or removes its own entries, and you can see what your other servers added. Give each server its own app addresses on the domain — if a name is already taken by another server, Nova says which one and suggests a free name. Each server needs its own Cloudflare Tunnel (Zero Trust → Networks → Tunnels → Create): a tunnel that runs on two machines would send visits to either one, so Nova refuses to publish on it.

Can I control several servers from one place?

Yes. Add your other servers under Servers in Nova web, then pick one to control it from the same page. Each server checks your browser itself, so the first time you approve your browser on that server, once.

Do I need to open ports on my router?

No. At home the app talks to the server directly. For access from anywhere, Nova uses a Cloudflare Tunnel with Cloudflare Access in front, or Tailscale if you already use it.

Is there an iPhone app? Can I use Nova with just an iPhone?

Not yet an app — but Nova web works on iPhone and iPad, and you don't need an Android phone:

  1. In Safari, open Nova at your server's address (https://your-server:8495 at home, or your Cloudflare address).
  2. Tap Get a code. On the server, run sudo nova approve with that code (or, if you already set them up, type a code from your authenticator app on the same screen).
  3. Tap Share → Add to Home Screen: Nova opens full screen with its own icon, like an app.
  4. In Nova → Security & privacy, add a passkey (Face ID or Touch ID) or authenticator codes. From then on they approve risky actions and new browsers — no Android phone or SSH needed.
What happens if I lose my phone?

Run sudo nova remove NAME on the server, or remove it from another phone. Its keys can never be used again.

Does it work without Docker?

Yes. Containers and the app store need Docker; status, drives, backups, alerts, diagnostics and the terminal don't.

Can Nova erase the wrong drive?

The server never offers the system drive, swap, or anything mounted or already in a pool. You type ERASE, confirm with your fingerprint, and the server re-checks the exact drives before it starts.

Is it free?

Yes — it's open source under the AGPL-3.0. The source, the server package and the Android app are all in the repository.
